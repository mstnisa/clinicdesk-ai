Privacy notice

ClinicDesk is a portfolio demo built by Mst. Awalunnisa. The clinic in it is made up. Please do not send real medical or personal information.

What is stored

Messages you send in the web chat or on WhatsApp are stored so the clinic dashboard can show the conversation. Phone numbers, email addresses and national ID numbers are removed from the stored text. If you book a demo appointment, the name and phone number you give are stored with the booking.

Who can see it

Anyone with the demo dashboard token can see conversations and bookings, because this is a public demo. Messages are sent to an AI model provider (Groq) to write the replies.

How long it is kept

The demo stores data only in temporary storage. Everything is deleted whenever the demo restarts, which usually happens at least once a day.

Deleting your data

To have something removed sooner, open an issue on GitHub.
